# BigBrotr Website

Official website and documentation for [BigBrotr](https://github.com/BigBrotr/bigbrotr) — a modular Nostr data archiving and monitoring system.

**Live at [bigbrotr.com](https://bigbrotr.com)**

## Stack

- [Astro](https://astro.build/) — static site generator
- [Starlight](https://starlight.astro.build/) — documentation theme
- [starlight-blog](https://github.com/HiDeoo/starlight-blog) — blog plugin

## Development

```bash
npm install
npm run dev       # Start dev server at localhost:4321
npm run build     # Build for production
npm run preview   # Preview production build
```

## Deployment

Deployed automatically to [Vercel](https://vercel.com/) on push to `main`.
