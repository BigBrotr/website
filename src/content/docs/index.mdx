## Three Pillars

<div class="pillar-grid">
  <div class="pillar-card discovery">
    <span class="pillar-icon">🔍</span>
    <h3>Discovery</h3>
    <p>Find relays across clearnet, Tor, I2P, and Lokinet. Bootstrap from seed files, discover new URLs from NIP-65 events and public APIs, then validate each candidate with a live WebSocket handshake.</p>
  </div>
  <div class="pillar-card monitoring">
    <span class="pillar-icon">📡</span>
    <h3>Health Monitoring</h3>
    <p>Six NIP-66 health tests — RTT latency, SSL certificates, DNS resolution, geolocation, network reachability, and HTTP status — plus NIP-11 relay information document fetching.</p>
  </div>
  <div class="pillar-card archiving">
    <span class="pillar-icon">🗄️</span>
    <h3>Event Archiving</h3>
    <p>Cursor-based synchronization collects events from validated relays. Content-addressed metadata deduplication via SHA-256 hashing ensures storage efficiency at scale.</p>
  </div>
</div>

## Architecture

Imports flow strictly downward through a **diamond DAG** — no cycles, no shortcuts:

<div class="arch-diagram">{`              services              Orchestration
             /   |   \\
          core  nips  utils          Infrastructure
             \\   |   /
              models                 Pure domain types`}</div>

<div class="pkg-grid">
  <div class="pkg-card">
    <div class="pkg-name">models</div>
    <p class="pkg-desc">Frozen dataclasses for Nostr concepts. Zero I/O. Fail-fast validation and content-addressed deduplication.</p>
  </div>
  <div class="pkg-card">
    <div class="pkg-name">core</div>
    <p class="pkg-desc">Connection pool with retry/backoff, database facade, base service, structured logging, Prometheus metrics.</p>
  </div>
  <div class="pkg-card">
    <div class="pkg-name">nips</div>
    <p class="pkg-desc">Protocol-aware I/O. NIP-11 relay info fetch; NIP-66 runs six health tests (RTT, SSL, DNS, Geo, Net, HTTP).</p>
  </div>
  <div class="pkg-card">
    <div class="pkg-name">utils</div>
    <p class="pkg-desc">DNS resolution, Nostr key management, WebSocket/HTTP transport with SSL fallback and SOCKS5 proxy support.</p>
  </div>
</div>

## Quick Start

```bash
# Clone and start the full stack
git clone https://github.com/BigBrotr/bigbrotr.git
cd bigbrotr/deployments/bigbrotr
docker compose up -d

# Run a single service
python -m bigbrotr seeder --once
python -m bigbrotr finder --log-level DEBUG
```
