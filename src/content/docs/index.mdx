## Three Pillars

<div class="pillar-grid">
  <div class="pillar-card">
    <h3>Discovery</h3>
    <p>Find relays across clearnet, Tor, I2P, and Lokinet. Seed from known sources, discover new relays from NIP-65 events and public APIs, then validate each candidate with a live WebSocket handshake.</p>
  </div>
  <div class="pillar-card">
    <h3>Health Monitoring</h3>
    <p>Continuous health checks using NIP-11 relay information documents and NIP-66 monitoring events. Measures RTT latency, SSL certificate validity, DNS resolution, geographic location, network reachability, and HTTP status.</p>
  </div>
  <div class="pillar-card">
    <h3>Event Archiving</h3>
    <p>Cursor-based event synchronization collects and archives Nostr events from validated relays. Content-addressed metadata deduplication ensures storage efficiency through SHA-256 hashing.</p>
  </div>
</div>

## Architecture

BigBrotr follows a **diamond DAG** dependency structure. Imports flow strictly
downward, ensuring clean separation of concerns:

<div class="arch-diagram">
{`            services          Orchestration
           /   |   \\
        core  nips  utils      Infrastructure
           \\   |   /
            models             Pure domain types`}
</div>

<CardGrid>
  <Card title="models" icon="document">
    Pure frozen dataclasses representing Nostr concepts. Zero I/O, zero external
    dependencies. Fail-fast validation and content-addressed deduplication.
  </Card>
  <Card title="core" icon="setting">
    Connection pool with retry and backoff, database facade, abstract base
    service, structured logging, and Prometheus metrics.
  </Card>
  <Card title="nips" icon="approve-check-circle">
    Protocol-aware I/O. NIP-11 fetches relay information documents; NIP-66 runs
    six health tests (RTT, SSL, DNS, Geo, Net, HTTP).
  </Card>
  <Card title="utils" icon="random">
    DNS resolution, Nostr key management, WebSocket and HTTP transport with SSL
    fallback and SOCKS5 proxy support.
  </Card>
</CardGrid>

## Quick Start

```bash
# Clone the repository
git clone https://github.com/BigBrotr/bigbrotr.git
cd bigbrotr/deployments/bigbrotr

# Start the full stack
docker compose up -d

# Run a single service
python -m bigbrotr seeder --once
python -m bigbrotr finder --log-level DEBUG
```
